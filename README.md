# tools.eubyt.dev

Ferramentas online para desenvolvedores — hash, JWT, Base64, JSON, UUID e mais.

Stack: Next.js 16, Tailwind CSS v4, i18n (`en` / `pt`).

## Rodar localmente

```bash
npm install
npm run dev
```

Abre em [http://localhost:3000](http://localhost:3000).

## Scripts

| Comando | Descrição |
| --- | --- |
| `npm run dev` | Desenvolvimento |
| `npm run build` | Build de produção |
| `npm run start` | Servidor de produção |
| `npm run typecheck` | Checagem de tipos |
